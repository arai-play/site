ARAI PLAY 수정본

변경 사항
1. 상단 로고를 ARAI로 변경하고 가운데 A를 겹글자 효과로 강조
2. 인기 작품 카드에 왕관(👑 인기) 표시
3. 피드백 팝업의 X 버튼이 정상적으로 닫히도록 수정
4. 작품 상세 화면에 작성자 수정/삭제 버튼 추가
5. 작품 등록 시 수정·삭제 코드 입력 필수
6. 수정/삭제 시 코드 확인 팝업 표시
7. 교사 관리 메뉴 진입 시 관리자 코드 확인 팝업 추가
8. 관리자 세션 로그아웃 기능 추가

테스트용 코드
- 기존 예시 작품 수정·삭제 코드: 1234
- 교사 관리 데모 코드: ARAI2026

중요
현재 GitHub Pages + localStorage 구조는 정적 사이트이므로 위 코드는 실제 보안 장치가 아닙니다.
브라우저 개발자 도구에서 JavaScript 내용을 볼 수 있으므로 실제 운영에는 Firebase Authentication + Firestore Security Rules가 필요합니다.
