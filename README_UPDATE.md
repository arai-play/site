이번 수정 사항

- 푸터 문구: 건강한 AI 활용, 행복한 학교 생활을 응원합니다!
- 설정 아이콘 클릭 시 관리자 로그인 창
- 피드백 창에 안내 문구 추가
- 기존 전체 로고/마스코트 구조 유지
