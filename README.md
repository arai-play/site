# 아라 AI PLAY

학생들이 AI로 만든 웹앱·게임·학습 프로그램을 서로 공유하는 **학교용 앱스토어형 허브 웹앱**입니다.

## 포함 기능

- 홈 화면
- 신규작
- 인기작
- 카테고리
- 작품 랭킹
- 검색 / 학년 필터
- 작품 상세 화면
- 외부 웹앱 실행 링크
- 추천 / 반응
- 피드백
- 학생 작품 등록
- 교사 승인 / 비공개 / 삭제
- 관리자 통계
- 반응형 모바일 화면

## 현재 데이터 저장 방식

현재 버전은 **localStorage**를 사용합니다.

따라서:
- GitHub Pages에 바로 배포할 수 있습니다.
- 서버 없이도 데모 및 학급 시연이 가능합니다.
- 하지만 학생 여러 명이 각자의 기기에서 입력한 내용이 서로 공유되지는 않습니다.

실제 학교 공동 사용 버전에서는 `app.js`의 localStorage 부분을 **Firebase Firestore** 또는 **Supabase**로 교체하는 것을 권장합니다.

## 실행 방법

1. 이 폴더의 `index.html`을 더블클릭합니다.
2. 또는 GitHub 저장소에 파일을 올립니다.
3. GitHub → Settings → Pages → Deploy from a branch를 선택합니다.
4. `main` / `(root)`를 선택하면 GitHub Pages 주소가 생성됩니다.

## 파일 구조

- `index.html` : 기본 화면
- `style.css` : 디자인
- `app.js` : 작품 데이터, 랭킹, 등록, 피드백, 관리자 기능

## 실제 서비스 전에 바꿀 부분

`app.js` 안의 예시 작품 URL은 `https://example.com`입니다.
학생 작품의 실제 URL로 바꾸거나, 웹 화면의 '작품 등록' 메뉴를 통해 테스트할 수 있습니다.

## 추천 다음 단계

1. Firebase Authentication으로 교사 로그인
2. Firestore로 작품·피드백 공동 저장
3. Firebase Storage로 대표 이미지 직접 업로드
4. 학생 등록 → 교사 승인 워크플로
5. 한 학생의 중복 추천 제한
6. 부적절한 피드백 신고/숨김
7. 주간 랭킹 자동 계산
